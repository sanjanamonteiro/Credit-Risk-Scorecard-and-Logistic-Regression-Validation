# Credit Risk Scorecard and Logistic Regression Validation

## Project Overview
This project implements a Credit Risk Scorecard using Logistic Regression in Python. It demonstrates how machine learning can be applied to classify credit risk and validate predictive performance.

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Implementation
1. Credit risk dataset generation
2. Data exploration and preprocessing
3. Feature scaling
4. Logistic Regression model training
5. Credit risk prediction
6. Model validation using Accuracy and ROC-AUC
7. Confusion matrix and ROC curve visualization
8. Credit risk scorecard generation
9. Exporting prediction and scorecard reports

## Dataset
A simulated dataset containing 1,000 records and six features is used for academic demonstration.

## Output Files
- Credit_Risk_Predictions.csv
- Credit_Risk_Scorecard.csv

## Execution
Implemented and executed using Google Colab.

## Disclaimer
This project uses simulated data and is intended for educational purposes only.
